## 功能

| 功能 | 默认值 | 说明 |
|---|---|---|
| 斧头秒破玻璃 `rsAxeInstantGlass` | `false` | 斧头点玻璃一下碎，含玻璃板、染色玻璃、遮光玻璃 |
| 无AI末影龙取龙息 `rsNoAiDragonBreath` | `false` | 空玻璃瓶对准无AI末影龙右键取龙息 |
